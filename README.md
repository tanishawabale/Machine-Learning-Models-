# Machine-Learning-Models-

**Objective**

Improve predictive performance by implementing and comparing advanced machine learning models.

**Models Implemented**

Random Forest

Gradient Boosting

Support Vector Machine (SVM)

K-Nearest Neighbors (KNN)

**Best Model:** Random Forest achieved the highest accuracy.

**Cross-Validation**

5-fold cross-validation was performed on the Random Forest model.

**Cross-validation scores:** 0.9995, 0.999, 0.655, 0.998, 0.999

**Average Accuracy:** 0.9301

**Conclusion**

Random Forest provided the best predictive performance among all tested models and showed good generalization ability.
